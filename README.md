# Open WebUI Computer

**For new setups, we recommend Open WebUI with Open Terminal.** Your AI can edit project files and run shell commands from chat.

[Set up Open WebUI](https://docs.openwebui.com/getting-started/quick-start/) → [Install Open Terminal](https://docs.openwebui.com/features/open-terminal/setup/installation/) → [Connect them](https://docs.openwebui.com/features/open-terminal/setup/connecting/)

## Standalone browser workspace

Open WebUI Computer (`cptr`) lets you edit files, review Git changes, and run a shell or coding agent on your own machine from a browser. Terminal sessions keep running when you close the tab.

![Open WebUI Computer workspace](./demo.png)

### Run locally

```bash
pip install cptr
cptr run
```

Open the URL printed in your terminal if your browser doesn't open automatically. Keep access private. Anyone who signs in has full access to your files and shell.
